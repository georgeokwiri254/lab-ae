# UAE Capitalism Lab: phone / Android version (PWA)

A business-empire simulation on the real UAE map. You build firms and supply chains, trade on simulated DFM and ADX stock markets, hire CEOs and run city economies across the seven emirates.

## Play on Android

1. In **Chrome** on the phone, open this repository's GitHub Pages address (Settings → Pages).
2. Tap **Install** on the banner, or open the ⋮ menu and choose **Add to Home screen** / **Install app**.
3. Start it from the home-screen icon. It runs full screen, like a normal app.

After the first visit the game works offline. Map tiles for areas you have already viewed are also cached.

## Phone controls

| Action | How |
|---|---|
| Open a menu (build, firms, finance, CEO …) | Bottom dock. Swipe it sideways to see all the buttons. |
| Pause or change game speed | `❚❚ 1 2 3 4 5` in the top bar |
| Move, zoom or tilt the map | Drag, pinch, or two-finger drag up/down |
| Build | 🏗 → pick a firm type → tap the map → confirm |
| Open a firm | Tap its neon dot |
| Save / load | ⚙ in the dock |

Saves are stored on the phone. The game also saves automatically every game month and whenever you leave the app. **Export save (.json)** opens the Android share sheet, so you can keep a copy in Drive or Files. To move a save between the PC app and the phone, export it on one and use **Import .json save** on the other.

This build is generated by `pwa/build.js` in the game source. Do not edit these files by hand.
